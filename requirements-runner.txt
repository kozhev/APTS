# =========================================================================
#  Host-process dependencies for the APTS single-process Runner.
#
#  These are ONLY what `python -m apts.cli run ...` needs on the host. The
#  scanners (sqlmap, katana, ffuf), the browser (Playwright/Chromium) and the
#  crawler live in the mcp-native container and are NOT installed here.
#
#  Pins are copied verbatim from the project's own requirements.txt so the
#  host matches the tested set. Derived from the actual third-party imports in
#  shared/ and agent/services/workers/:
#    fastapi, uvicorn, httpx, pydantic, psycopg, mcp,
#    langchain_core, langgraph, langchain_openai (lazy, shared/llm.py),
#    langfuse + the umbrella `langchain` (langfuse.langchain CallbackHandler).
#
#  Recommended: install into a fresh virtualenv (see CLAUDE.md / `make setup`).
# =========================================================================
